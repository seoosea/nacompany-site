# 나컴퍼니 홈페이지 — 따라 하기 안내서

주식회사 나컴퍼니 회사 홈페이지(playsteam.co.kr) 파일입니다.
기사는 관리자 화면(playsteam.co.kr/admin)에서 쓰고, 저장하면 몇 분 뒤 홈페이지에 자동으로 나타납니다.

---

## 처음 한 번만 하는 일

### 1단계. 깃허브에 저장소 만들기

1. github.com에 로그인합니다.
2. 오른쪽 위 **＋** → **New repository**를 누릅니다.
3. Repository name에 `nacompany-site`를 적습니다.
4. **Public**을 고릅니다.
   - 무료로 사이트를 공개하려면 Public이어야 합니다.
   - 사이트 파일이 공개되지만, 비밀번호나 개인정보는 들어 있지 않으니 괜찮습니다.
5. 다른 칸은 그대로 두고 **Create repository**를 누릅니다.

### 2단계. 파일 올리기

Claude가 직접 올려 드릴 수도 있습니다. 직접 하실 때는:

1. 받은 압축 파일을 풉니다.
2. 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누릅니다.
3. 압축을 푼 폴더 **안의 내용 전부**를 끌어다 놓습니다.
   - 맥에서는 `.github` 폴더가 숨겨져 있어 안 보일 수 있습니다. Finder에서 `Command + Shift + .`(마침표)를 누르면 보입니다. **이 폴더가 꼭 올라가야** 자동 공개가 됩니다.
4. 아래 **Commit changes**를 누릅니다.

### 3단계. 관리자 화면에 저장소 이름 알려 주기

1. 저장소에서 `src` → `admin` → `config.yml` 파일을 엽니다.
2. 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
3. 아래 줄을 찾습니다.
   ```
   repo: 깃허브아이디/저장소이름
   ```
4. 실제 값으로 바꿉니다. 예: 깃허브 아이디가 `nacompany`라면
   ```
   repo: nacompany/nacompany-site
   ```
5. **Commit changes**를 누릅니다.

### 4단계. 사이트 공개 켜기

1. 저장소 위쪽 **Settings** → 왼쪽 메뉴 **Pages**로 갑니다.
2. **Source**를 **GitHub Actions**로 바꿉니다.
3. 저장소 위쪽 **Actions** 탭을 누르면 "사이트 공개" 작업이 돌아가는 게 보입니다. 초록색 체크가 뜨면 성공입니다. (2~3분)

### 5단계. playsteam.co.kr 주소 연결

**① 도메인을 산 곳(가비아, 후이즈 등)의 DNS 설정**에서 아래처럼 넣습니다.

| 종류 | 이름(호스트) | 값 |
|---|---|---|
| A | @ (비워 두기) | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | 깃허브아이디.github.io |

기존에 @ 나 www 로 들어 있던 다른 A·CNAME 기록이 있으면 지웁니다.

**② 깃허브 Settings → Pages**의 **Custom domain**에 `playsteam.co.kr`을 적고 **Save**를 누릅니다.

**③** 몇 분~몇 시간 뒤 확인 표시가 뜨면 **Enforce HTTPS**에 체크합니다.

> DNS가 전 세계에 퍼지는 데 길게는 하루가 걸릴 수 있습니다. 바로 안 열려도 기다려 보세요.

### 6단계. 관리자 로그인 열쇠(토큰) 만들기

관리자 화면은 깃허브 "토큰"으로 로그인합니다. 토큰은 **이 저장소만 고칠 수 있는 비밀번호**라고 생각하시면 됩니다.

1. 깃허브 오른쪽 위 프로필 사진 → **Settings**
2. 왼쪽 맨 아래 **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**
3. 이렇게 채웁니다.
   - Token name: `나컴퍼니 관리자`
   - Expiration: 원하는 기간 (예: 1년. 기간이 끝나면 새로 만들면 됩니다)
   - Repository access: **Only select repositories** → `nacompany-site`
   - Permissions → Repository permissions → **Contents**: **Read and write**
4. **Generate token**을 누르고 나온 긴 글자를 복사해 **안전한 곳**(비밀번호 관리 앱 등)에 보관합니다. 이 화면을 닫으면 다시 볼 수 없습니다.
5. **이 토큰은 아무에게도 보내지 마세요.** Claude에게도 보내실 필요가 없습니다.

### 7단계. 관리자 화면 들어가기

1. `playsteam.co.kr/admin`에 들어갑니다. (주소 연결 전이라면 `깃허브아이디.github.io/nacompany-site/admin`)
2. **토큰으로 로그인(Sign In with Token)**을 누르고 6단계에서 만든 토큰을 붙여 넣습니다.
3. 왼쪽에 **PLAYSTEAM 기사**와 **사이트 관리**가 보이면 성공입니다.

## 평소에 하는 일

### 기사 쓰기

1. 관리자 화면 → **PLAYSTEAM 기사** → **새 기사**
2. 제목, 호수, 코너, 분류, 지역, 날짜를 채웁니다.
3. **레이아웃과 내용**에서 레이아웃을 고릅니다.
   - 큰 사진 — 대회 수상, 큰 행사
   - 사진 3장 — 행사 현장 (첫 사진이 크게 보임)
   - 인용문 — 참가자·학생의 한마디
   - 숫자 강조 — 참가 인원, 운영 횟수
   - 짧은 소식 — 개강, 공지
4. 사진을 올리면 자동으로 알맞은 크기로 줄어듭니다. 얼굴이 잘리면 **잘릴 때 보일 부분**을 위·가운데·아래로 바꿔 보세요.
5. 칸마다 글자 수 제한이 있어서 넘치면 저장되지 않고 알려 줍니다.
6. **저장(Save)** 을 누르면 2~3분 뒤 홈페이지에 나타납니다.
   - 아직 공개하기 싫으면 **공개**를 끄고 저장하세요. 관리자 화면에만 남습니다.

> 처음에 예시 기사 5개(공개 꺼짐)가 들어 있습니다. 레이아웃별 모양을 보는 용도이니, 내용을 바꿔서 쓰시거나 지우셔도 됩니다.

### 연락처·링크·실적 바꾸기

관리자 화면 → **사이트 관리**에서 바꿉니다.

- **연락처 · 링크 · 슬로건**: 전화, 메일, 주소, 학원 사이트, 문의서(구글 설문지) 주소, 구독 신청(스티비) 주소, 회사 소개서 PDF
  - 비어 있는 칸은 홈페이지에서 자동으로 숨겨집니다. 채우면 그 버튼이 나타납니다.
- **첫 화면 숫자 · 프로젝트 예시 · 실적**: 23년 같은 숫자, SoloRide 같은 프로젝트 예시, 연도별 실적, 대표 작품 포스터

### 검색에 나오게 하기 (한 번만)

1. **네이버 서치어드바이저**(searchadvisor.naver.com)에 로그인 → 사이트 등록 → `https://playsteam.co.kr`
2. 소유 확인 방법에서 **HTML 태그**를 고르면 `content="..."` 안에 긴 글자가 있습니다. 그 글자만 복사해 관리자 화면 → 사이트 관리 → **네이버 서치어드바이저 확인 코드**에 붙여 넣고 저장합니다.
3. 몇 분 뒤 네이버에서 **소유 확인**을 누릅니다.
4. 확인되면 **요청 → 사이트맵 제출**에 `https://playsteam.co.kr/sitemap.xml`을 넣습니다.
5. 구글 서치 콘솔도 같은 방식입니다.

## 문제가 생겼을 때

- 저장했는데 홈페이지가 안 바뀌면: 저장소 **Actions** 탭을 봅니다. 빨간 ✕가 있으면 그 화면을 캡처해서 Claude에게 보여 주세요.
- 관리자 로그인이 안 되면: 토큰 기간이 끝났을 수 있습니다. 6단계대로 새로 만드세요.
- 모양을 크게 바꾸고 싶으면: Claude에게 이 저장소와 바꾸고 싶은 내용을 알려 주세요.

## 파일 구조 (참고용)

```
src/
  index.njk                  첫 화면
  playsteam/index.njk        PLAYSTEAM 목록
  playsteam/articles/        기사 (관리자 화면이 여기에 저장)
  _data/site.json            연락처·링크 (관리자 화면 → 사이트 관리)
  _data/home.json            숫자·실적 (관리자 화면 → 사이트 관리)
  _includes/                 공통 틀, 기사 레이아웃
  assets/css/site.css        색·글꼴·모양
  assets/uploads/            관리자 화면에서 올린 사진
  admin/                     관리자 화면 설정
.github/workflows/deploy.yml 자동 공개 설정
```
